WHAT IT WON’T DO

It updates everything, and knows when to stop.

Many tools can run every updater. This one is defined by what it refuses to do.

    PLATFORMS

    Three scripts. Equal on every system.

    Linux
    linux/update-everything.sh

    The distribution’s own package manager (16 supported, from APT to NixOS), then Snap, Flatpak and Homebrew.

    macOS
    macos/update-everything.sh

    macOS system updates, then the Mac App Store, Homebrew, MacPorts and Nix.

    Windows
    windows/update-everything.ps1

    Windows Update, then WinGet, Chocolatey, Scoop, Patch My PC and the Microsoft Store.
